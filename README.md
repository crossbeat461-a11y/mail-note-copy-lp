# Mail Note Copy LP

Thunderbird アドオン [Mail Note Copy](https://addons.thunderbird.net/addon/mail-note-copy/) のランディングページです。

静的 HTML のみです。Vercel にこのフォルダを出しています。

- 公開: https://mail-note-copy-lp.vercel.app/
- 製品: 選んだメール 1 通を `日付_件名.md` として保存。場所は保存ダイアログ
- 版: 1.1.0（Experiment API なし）
- 言語切替: 右上 JP / EN
