Mail Note Copy

メールを Obsidian の Markdown ノートとして保存します。プロパティに差出人・宛先・件名を残し、本文と添付も同じフォルダへ。保存先のパスを見てから選べます。固定フォルダを置けば、別の Vault にも送れます。

Save a Thunderbird message as an Obsidian Markdown note. Properties keep from, to, and subject. The body and attachments land in the same folder. You see the path before you save, and pinned folders can point at other vaults.

メール 1 通が、そのまま 1 ノートになる One message becomes one note

クリップボードに本文だけ残して、あとで貼る作業ではありません。ファイル名は 日付_件名.md。プロパティに各情報を書き、本文を Markdown にし、添付ファイルも置きます。

This is not a clipboard-only workflow. The filename is date_subject.md. Properties store the headers, the body becomes Markdown, and attachment files are written there too.

MD

プロパティ付きの Markdown

date / from / to / cc / bcc / subject / attachments / message-id を YAML に残します。Obsidian のプロパティとして検索できます。

Markdown with properties

YAML keeps date, from, to, cc, bcc, subject, attachments, and message-id so Obsidian can search them.

本文と添付を一緒に

ノートの下に添付へのウィキリンクを置きます。Excel や PDF も、ノートと同じフォルダに実ファイルとして保存します。

Body plus attachments

The note gets wiki-links to attachments. Excel, PDF, and other files are written next to the note.

See the path, then choose

Current Obsidian folder, recents, and pins. Paths stay visible, so other vaults are first-class destinations.

使い方は簡単。3つのSTEP Three steps

保存先は複数。Vault も複数。 Several destinations. Several vaults.

仕事用と個人用で Vault が分かれていても、設定にフルパスを指定できます。保存のたびに深いフォルダを辿り直す煩わしさはありません。

  • 固定フォルダ（最大 16）… よく使う Inbox や Mail フォルダ。名前を付けて並べ替えできます。
  • 今開いている場所… Obsidian が最後に見ていたフォルダを検出します。
  • 最近使った場所（最大 8）… さっき保存したフォルダが残ります。
  • 参照して選ぶ… その場で別のフォルダを指定できます。

固定フォルダはオプションです。最初は最近使った場所だけでも使えます。メニューの「保存先を管理…」から追加・改名・削除できます。

Work and personal vaults can each have a full path in settings. You do not have to walk a deep tree every time you save.

  • Pinned folders (up to 16) — Inbox or Mail folders you reuse, with your own labels.
  • Current folder — the folder Obsidian last had open.
  • Recents (up to 8) — the last places you saved to.
  • Browse — pick any other folder on the spot.

Pins are optional. Recents are enough to start. Add, rename, or remove pins from “Manage destinations…”.

プロパティに残る情報 What the properties keep

ファイル名は YYYY-MM-DD_件名.md です。Re: や Fwd: は外します。本文は HTML なら Markdown に直し、なければプレーンテキストを使います。

The filename is YYYY-MM-DD_subject.md. Re: and Fwd: are stripped. HTML bodies become Markdown; otherwise the plain text is used.

使い方 How to use it

1. メールを 1 通選ぶ

一覧または表示中のメールで右クリックします。いまは先頭の 1 通だけを保存します。複数選択の一括保存はこれから対応予定です。

1. Select one message

Right-click in the list or the open message. Version 1.0.0 saves the first selected message. Bulk save is planned.

2. メニューを選ぶ

本文をコピーはクリップボードへ。保存先を選んで保存はノートだけ。添付も保存は同じフォルダに添付ファイルも保存します。

2. Pick a menu

Copy body goes to the clipboard. Save with destination writes the note. Save with attachments also saves the attachment files in the same folder.

3. 保存ダイアログを見て保存する

固定・今の場所・最近・参照の順に並びます。選んだフォルダに 日付_件名.md ができ、添付メニューならファイルと ## 添付 のリンクが付きます。一度設定すると次から自動表示されています。

3. See the save dialog, then save

Pins, current folder, recents, then browse. The note is date_subject.md. Attachment mode adds files and a ## Attachments list. After you set them once, they show up automatically next time.

もう少し詳しく A bit more detail

Thunderbird の言語に合わせる

日本語の Thunderbird では日本語、それ以外では英語の画面になります。設定や完了ダイアログも同じです。

Follows Thunderbird’s language

Japanese Thunderbird gets Japanese UI. Other locales get English, including options and the finish dialog.

通信はしません

メールとファイルは手元のディスクにだけ書きます。外部へ送信する処理はありません。プライバシーポリシーは不要です。

No network calls

Mail and files stay on your disk. Nothing is sent out, so there is no privacy policy page to host.

An Experiment API writes to the chosen folder. Install the signed build from Thunderbird Add-ons.

よくある質問 Questions

今開いているフォルダへ、確認なしで保存しますか？Does it silently save into the current Obsidian folder?

しません。毎回、パスが見える画面で場所を選びます。今の場所は候補のひとつです。

No. You always pick a visible path. The current folder is only one of the choices.

複数のメールを一度に保存できますか？Can I save several messages at once?

1.0.0 は先頭の 1 通だけです。複数保存が必要なら GitHub の Issues に書いてください。

1.0.0 saves the first message only. Ask on GitHub Issues if you need bulk save.

添付のファイル名はプロパティにあるのに、実ファイルが無いことがありますか？Can the properties list a file that was not written?

「添付も保存」を選んでください。ノート保存だけだと、名前はプロパティに残ってもファイルは置きません。

Use “Save with attachments”. Note-only save can list names in properties without writing the files.

サポートはどこですか？Where is support?

GitHub Issues へどうぞ。ソースは同じリポジトリにあります。

Use GitHub Issues. Source lives in the same repository.
