Mail Note Copy

Thunderbird のメールを Obsidian 向けの Markdown ノートに保存するアドオンです。選んだ 1 通を保存し、場所は Thunderbird の保存ダイアログで選びます。本文だけコピーして貼ることもできます。

A Thunderbird add-on that saves one selected email as an Obsidian Markdown note. Choose the folder in Thunderbird’s save dialog. You can also copy the body and paste it.

メール 1 通が、そのまま 1 ノートになる One message becomes one note

クリップボードに本文だけ残して、あとで貼る作業ではありません。ファイル名は 日付_件名.md。プロパティに各情報を書き、本文を Markdown にし、添付ファイルも置きます。

This is not a clipboard-only workflow. The filename is date_subject.md. Properties store the headers, the body becomes Markdown, and attachment files are written there too.

MD

プロパティ付きの Markdown

date / from / to / cc / bcc / subject / attachments / message-id を YAML に残します。Obsidian のプロパティとして検索できます。

Markdown with properties

YAML keeps date, from, to, cc, bcc, subject, attachments, and message-id so Obsidian can search them.

📎

本文と添付を一緒に

ノートの下に添付へのウィキリンクを置きます。Excel や PDF も、ノートと同じフォルダに実ファイルとして保存します。

Body plus attachments

The note gets wiki-links to attachments. Excel, PDF, and other files are written next to the note.

📁

保存ダイアログで場所を選ぶ

固定フォルダの一覧はありません。保存のたびに、Thunderbird の保存ダイアログで場所と名前を決めます。OS が直前のフォルダを覚えていることがあります。

Choose the folder in the save dialog

There is no pinned folder list. Each save uses Thunderbird’s save dialog. The OS often remembers the last folder.

使い方は簡単。3つのSTEP Three steps

場所は、その都度選びます。 You choose the folder each time.

仕事用と個人用で Vault が分かれていても、保存ダイアログでそのフォルダを選べば足ります。アドオンがフォルダを覚えたり、Obsidian を探したりはしません。

  • ツールバー… 右上の「ノートを保存」がいちばんよく使う入口です。
  • 右クリック… 「本文をコピー」「ノートを保存」「ノートと添付を保存」。
  • 保存…… Thunderbird の保存ダイアログで場所と名前を決めます。
  • 本文をコピー… Markdown をクリップボードへ入れ、今開いているノートへ貼ります。

添付もあるメールは、確認画面で添付の保存を選べます。本文のあと、ファイルごとに保存ダイアログが出ます。

Work and personal vaults are just folders. Pick them in the save dialog. The add-on does not remember a folder list or look for Obsidian.

  • Toolbar — Save note on the right is the main entry point.
  • Right-click — Copy body, Save note, or Save note and attachments.
  • Save… — pick the folder and name in Thunderbird’s save dialog.
  • Copy body — puts Markdown on the clipboard so you can paste into an open note.

If the message has attachments, turn that on in the confirmation window. After the note, a save dialog appears for each file.

プロパティに残る情報 What the properties keep

ファイル名は YYYY-MM-DD_件名.md です。Re: や Fwd: は外します。本文は HTML なら Markdown に直し、なければプレーンテキストを使います。

The filename is YYYY-MM-DD_subject.md. Re: and Fwd: are stripped. HTML bodies become Markdown; otherwise the plain text is used.

使い方 How to use it

1. メールを 1 通選ぶ

一覧または表示中のメールで 1 通選びます。複数通の一括保存はありません。

1. Select one message

Display the message, or select one in the list. Version 1.1.0 does not save several messages at once.

2. 「ノートを保存」を押す

ツールバー右上の ノートを保存 が入口です。右クリックの 本文をコピー、ノートを保存、ノートと添付を保存 でも同じ操作ができます。

2. Click Save note

The Save note button on the right of the toolbar is the main entry. Right-click also has Copy body, Save note, and Save note and attachments.

3. 保存するか、コピーする

確認画面の 保存… で場所と名前を決め、日付_件名.md を置きます。本文をコピーならクリップボードへ入れます。添付を選んだ場合は、ファイルごとに保存ダイアログが出ます。

3. Save or copy

Save… opens the save dialog for date_subject.md. Copy body puts Markdown on the clipboard. If you save attachments, a dialog appears for each file.

もう少し詳しく A bit more detail

Thunderbird の言語に合わせる

日本語の Thunderbird では日本語、それ以外では英語の画面になります。設定や完了ダイアログも同じです。

Follows Thunderbird’s language

Japanese Thunderbird gets Japanese UI. Other locales get English, including options and the finish dialog.

通信はしません

メールとファイルは手元のディスクにだけ書きます。外部へ送信する処理はありません。プライバシーポリシーは不要です。

No network calls

Mail and files stay on your disk. Nothing is sent out, so there is no privacy policy page to host.

Thunderbird 115 以降

1.1.0 は Experiment API を使いません。保存は Thunderbird の保存ダイアログです。公式ストアの署名済みを入れてください。

Thunderbird 115+

1.1.0 does not use an Experiment API. Saving uses Thunderbird’s save dialog. Install the signed build from Thunderbird Add-ons.

It is listed on Thunderbird Add-ons. Requires Thunderbird 115 or later. Use GitHub Issues for problems.

よくある質問 Questions

今開いているフォルダへ、確認なしで保存しますか？Does it silently save into the current Obsidian folder?

しません。毎回、Thunderbird の保存ダイアログで場所を選びます。OS が直前のフォルダを覚えることはあります。

No. You pick the folder in Thunderbird’s save dialog each time. The OS often remembers the last folder.

複数のメールを一度に保存できますか？Can I save several messages at once?

1.1.0 は 1 通だけです。複数保存が必要なら GitHub の Issues に書いてください。

1.1.0 saves one message only. Ask on GitHub Issues if you need bulk save.

添付のファイル名はプロパティにあるのに、実ファイルが無いことがありますか？Can the properties list a file that was not written?

確認画面で添付の保存を選んでください。ノートだけ保存すると、名前はプロパティに残ってもファイルは置きません。

Turn on attachment saving in the confirmation window. Note-only save can list names in properties without writing the files.

サポートはどこですか？Where is support?

GitHub Issues へどうぞ。ソースは同じリポジトリにあります。

Use GitHub Issues. Source lives in the same repository.
